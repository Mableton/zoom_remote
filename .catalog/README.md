# Zoom Remote

Remote control for **Zoom Workplace** on macOS and Windows. Connect over USB or
Bluetooth, the Flipper acts as a keyboard and sends Zoom's own shortcuts.

Not affiliated with Zoom Video Communications, Inc.

## Features

- Mute, video, raise hand, share and participants right on the buttons
- Estimated mic and camera state on screen
- Share mode: D-pad = arrow keys, OK = Enter, hold OK = Tab, Back = Escape
- All Zoom hotkeys in a categorized menu, with info on focus and global use
- Leave meeting only after confirmation
- English and German UI
- USB mode and Bluetooth profile are restored on exit

## Usage

1. Pick your OS and the connection. On Windows also pick the keyboard layout.
2. Keep the Zoom meeting window focused, or enable the shortcuts as global in
   Zoom under Settings > Keyboard shortcuts.
3. Short and long presses are shown on the remote screen.

Tested on macOS with Zoom Workplace 7.0.6. Windows shortcuts follow Zoom's
documentation but are untested so far.
